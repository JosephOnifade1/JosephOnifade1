## Featured Work

### Hobnob AI — Multi-Model AI Chat Platform
Chat platform routing between Claude, GPT, and Grok, built on Supabase Edge Functions. Full custom design system ("ink-green lounge" — dark ground, brass accent) and hand-built UI, no template scaffolding.

### SoleForge — 3D Sneaker Configurator
Real-time product configurator built with Blender-sourced models, Three.js, and React Three Fiber. Bridges the 3D design and frontend engineering sides of my work in one product.

### Personal Portfolio
Vite + React site with custom Three.js animation work, a burgundy/cream identity system, and Playfair Display/DM Sans typography — deployed on Vercel.

### GigRank / Borynx — Freelancer Community Platform
Reddit-style platform for freelancers, built on React + Supabase with full auth, RLS policies, voting, and category filtering from scratch.

### AI Strategy Coaching App
Claude-powered coaching tool guiding users through structured strategy sessions, with session persistence and canvas sync via Supabase Edge Functions.

### Client Delivery — APEX (Mobile)
React Native / Expo app built for a GCC motor community client — fully async delivery, no calls, production handoff.
