## About

I'm a freelance full-stack developer and AI automation specialist based in Nigeria, working asynchronously with clients across the United States, United Kingdom, Canada, the EU, and the UAE. I take products from a rough brief to production — web applications, conversational AI systems, automation pipelines, and interactive 3D experiences — without the overhead or timelines of an agency.

Alongside client work, I'm completing a degree in Industrial Design. That training shapes how I build: form, usability, and visual systems get the same attention as architecture and code — which means I can own the product-design and 3D side of a build, not just the engineering.

## How I Work

- **Async-first.** Written briefs, clear milestones, and documented handoffs — I work across time zones without needing calls to keep a project moving.
- **Production-ready by default.** Authentication, data security, error handling, and deployment are part of the build, not follow-up work.
- **Design-literate engineering.** An Industrial Design background means the interface, motion, and visual system get the same care as the architecture.
- **Honest scoping.** I read the brief thoroughly before quoting, so the estimate reflects the actual work.
